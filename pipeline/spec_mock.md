# 주간 모의고사 형식: `data/mocks/YYYY-MM-DD.json` (토요일)

앱의 테스트 탭에 시험지처럼 보인다. 사용자는 앱 타이머로 손글씨 답안을 쓰고, "채점 요청 복사"로 Claude에 채점을 맡긴다. 모범 목차와 키워드는 "다 쓴 뒤 열어보기"를 눌러야 보인다.

## 필드

| 키 | 내용 |
|---|---|
| `date` | 토요일 날짜 |
| `title` | 4~50자. 예: `1단계 4주차 모의: 터널·교량 중심` |
| `guide` | 안내 문장 1~3개(선택). 예: `1교시는 13문 중 10문을 골라 100분 안에 쓴다` |
| `notice` | 문제가 없는 날(실제 시험일 등)의 안내문 |
| `p1` | 1교시 단답 `{"t","k","x"}` 목록 |
| `p2`·`p3`·`p4` | 논술 `{"t","o","fig","u","x"}` 목록 |

문항 수는 `tool.py mock-brief`가 알려 주는 형식을 그대로 따른다(`check-mock`이 개수를 검사한다).

```json
{"date":"2026-10-24","title":"진단 모의: 1교시 단답","guide":["13문 중 10문을 골라 100분 안에 쓴다","문제당 1~1.5면, 정의 → 원리·그림 → 특징·유의사항 순서"],
 "p1":[
  {"t":"하천 수제(水制)","k":["흐름 제어·유속 감소","투과·불투과","상향·직각·하향"],"x":["140-1-05"]},
  {"t":"상수관로 공기밸브의 기능과 설치 위치","k":["공기 배출·흡입","상향 돌출부 정상","관경별 형식"],"x":["137-1-11"]}
 ]}
```

```json
"p2":[{"t":"하천 제방의 파괴원인과 방지대책을 설명하시오.","u":11,"x":["140-3-02"],
 "o":["개요: 제방 기능과 파괴 유형","월류 파괴: 원인, 여유고 부족","침투 파괴: 파이핑·보일링, 누수","활동 파괴: 비탈면 활동, 수위 급강하","방지대책: 단면 확대, 차수·배수, 호안","시공 유의사항: 다짐 관리, 구조물 접속부","결론: 기후변화 대응, 유지관리"],
 "fig":"제방 단면의 침투선과 대책 위치"}]
```

## 문항 고르기

- 1교시: 13문 중 9~10문은 브리프의 기출 재출제형 후보에서, 3~4문은 같은 범위에서 아직 기출에 없지만 나올 만한 용어(최근 개정 기준, 신기술, 사고 이슈)로 만든다. 새 용어도 `k`에 채점용 키워드를 단다.
- 논술: 브리프의 논술 후보(아직 모범 목차가 없는 기출)를 우선 쓰고, 교시마다 단원을 섞는다. 기출을 그대로 쓰면 `x`에 id를 넣는다(백로그에서 지워진다).
- 지난 10주 모의에 쓴 기출은 브리프에서 빠져 있다.

## 반드시 지킬 것

1. 모범 목차·키워드의 수치와 기준은 1차 출처로 확인한 것만 쓴다. 모르면 빼고 넣지 않는다.
2. 사용자에게 보이는 글에 메타 문구("Claude", "사용자님", "제가")와 마크다운 기호를 넣지 않는다.
3. 시험지 문체로 쓴다. 논술 문제는 "~을 설명하시오."로 끝낸다. 1교시는 용어만 써도 된다(앱이 복사할 때 "~에 대하여 설명하시오."를 붙인다).
