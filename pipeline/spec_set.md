# 세트 파일 형식: `data/sets/YYYY-MM-DD.json`

앱(기술사 6개월)이 이 JSON을 받아 그대로 화면에 보여 준다. 읽는 사람은 토목시공기술사 필기(제142회)를 혼자 준비하는 건설 실무자다. 출퇴근길에 휴대폰으로 읽고, 저녁에 논술을 손으로 쓴다.

## 필드

| 키 | 형식 | 내용 |
|---|---|---|
| `date` | `"YYYY-MM-DD"` | 파일명과 같게 |
| `title` | 4~40자 | 오늘 주제가 드러나는 제목. 예: `상수관로 준공 검사: 수압시험과 공기밸브` |
| `goal` | 한 문장(선택) | 오늘 끝나면 할 수 있는 것. 예: `관로 준공 전 검사 항목을 기준값까지 말할 수 있다` |
| `week` | 정수 | 브리프의 주차 |
| `units` | 정수 목록 | 오늘 다루는 단원 번호(1~16) |
| `cards` | 목록 | 브리프 규칙 개수. 새 용어 + 기존 카드(ref) |
| `quiz` | 5문 | 오늘 카드에서 낸 문제 |
| `essay` | 객체 | 논술 1문제와 모범 목차 |
| `tasks` | 3~4개 | 오늘 할 일 |
| `check` | 0~3개 | 확신하지 못한 내용(없으면 `[]`) |

### 새 용어 카드

```json
{"t":"상수관로 수압시험","u":13,"f":3,"x":["134-1-05"],
 "d":"매설한 상수관로의 수밀성과 접합부 안전성을 확인하는 시험으로, 일부 되메우기로 관을 고정하고 물을 채워 24시간 이상 두어 공기를 뺀 뒤 시험압력까지 서서히 올린다. 시험압력은 배관의 경우 최고 사용압력의 1.5배(최소 0.75MPa)이고, 60분 유지해 압력 강하가 0.02MPa 이하이면 합격이다. 시험 구간은 제수밸브와 제수밸브 사이가 원칙이다.",
 "k":["24시간 충수·공기 빼기","최고 사용압력 × 1.5","최소 0.75MPa","60분 0.02MPa 이하","제수밸브 사이 구간"],
 "basis":"KCS 57 30 35:2024 표 1.5-1",
 "plus":"하수관로 수밀시험(누수·침입수·공기압)과 비교해 외우면 헷갈리지 않는다.",
 "field":"준공 전 시험 성적서에 시험압력·유지시간·강하량이 빠지지 않았는지 공무가 확인한다."}
```

- `t` 용어(2~60자). 덱(pipeline/deck.json)에 같은 용어가 있으면 쓰지 말고 ref로 넣는다. `tool.py check-set`이 막는다.
- `d` 정의 2~4문장(120~700자). 답안에 그대로 옮겨 쓸 수 있는 문어체(~이다, ~한다). 첫 문장은 정의, 다음은 원리·종류·기준값, 끝은 시공 유의사항이나 대책.
- `k` 1교시 답안 소제목이 되는 키워드 4~6개(각 30자 이하).
- `u` 단원 번호, `f` 출제 빈도(3 자주, 2 보통, 1 드묾), `x` 관련 1교시 기출 id 목록(브리프 후보의 id를 넣어야 백로그에서 지워진다).
- `basis` 수치·기준을 확인한 1차 출처(기준 번호나 법령 조항). 수치가 있으면 반드시 쓴다.
- `plus` 함께 외우면 좋은 비교·연결 한 문장(선택), `field` 현장 적용 한 줄(선택).

### 기존 카드

```json
{"ref":"K34","plus":"수압시험 전 공기밸브로 관 안 공기를 충분히 빼야 압력 강하를 바로 판정할 수 있다."}
```

`ref`는 pipeline/deck.json의 id만 쓴다. 정의는 앱에 이미 있으므로 `t`·`d`를 쓰지 않는다. 오늘 새 용어와 이어지는 한 문장을 `plus`에 붙이면 좋다.

### 퀴즈

```json
{"q":"상수관로(배관) 수압시험의 시험압력으로 옳은 것은?","o":["최고 사용압력의 1.0배","최고 사용압력의 1.5배(최소 0.75MPa)","최고 사용압력 + 0.5MPa","최고 사용압력의 2.0배"],"a":1,"ex":"배관은 최고 사용압력의 1.5배, 최소 0.75MPa로 60분 유지한다.","u":13}
{"q":"하수관로 누수시험은 지하수위가 관 상단 위 0.5m 이상일 때 한다.","o":["맞다","틀리다"],"a":1,"ex":"0.5m 미만일 때 누수시험, 그 이상이면서 지하수위를 낮출 수 없으면 침입시험을 한다.","u":13}
```

- 4지선다는 보기 4개, OX는 `["맞다","틀리다"]`. `a`는 정답 보기의 번호(0부터).
- 수치·구분·순서처럼 헷갈리는 지점을 묻는다. 오답 보기는 그럴듯하게. 정답 번호를 섞는다.

### 논술

```json
{"t":"노후 하수관로의 문제점과 상태평가 기반 개·보수공법 선정 방안을 설명하시오.","u":13,"x":["139-4-04"],
 "o":["개요: 노후관 증가, 불명수·지반침하","노후관 문제점: 파손·이음부 이탈·침입수, 도로 함몰","상태평가: CCTV 조사, 결함 등급, 우선순위","공법 분류: 전면 교체, 부분 보수, 비굴착 갱생","공법 선정 기준: 결함 유형·관경·통수능·교통 영향","시공 유의사항: 부단수 우회, 품질 검사, 수밀시험","결론: 생애주기 관리, 상태 데이터 축적"],
 "fig":"결함 등급별 공법 선정 흐름도",
 "p":"상태평가 결과와 공법 선정을 연결해 설명하는지가 채점 핵심"}
```

- 기술사 답안 순서(개요 → 원인·특징 → 방법·대책 → 시공 유의사항 → 현장 사례 → 결론·최신 경향)로 소제목 5~7개, 소제목마다 키워드 2~3개.
- `x`는 2~4교시 기출 id(브리프 논술 후보). `fig`는 답안에 넣을 그림·표 1개.

### 과제·확인

```json
"tasks":["새 용어 4개를 소리 내어 30초씩 설명하기","논술 1문제 25분 손글씨 → 사진 찍어 첨삭 요청","퀴즈 틀린 문제는 오답 노트에서 저녁에 한 번 더"],
"check":["공기밸브 설치 간격의 수치 기준은 1차 출처를 찾지 못해 넣지 않음"]
```

## 반드시 지킬 것

1. 수치·기준값·법령 조항은 WebSearch/WebFetch로 1차 출처(국가건설기준센터 KDS·KCS, 국가법령정보센터 현행 법령·행정규칙, 국토교통부·환경부 고시)를 확인한 것만 쓴다. 확인하지 못한 수치는 빼고 `check`에 적는다. 모르는 것을 그럴듯하게 채우지 않는다.
2. 법령·고시·설계기준은 오늘 기준 현행본으로 쓴다. 국가건설기준센터에 옛 판만 올라 있는 기준(예: 상수도 KDS 57·KCS 57은 2017판)은 국가법령정보센터 행정규칙에 첨부된 현행 개정전문으로 확인한다. 최근 바뀐 값(예: 건설공사 사후평가 작성 기한 60일 → 120일)은 새 값으로 쓰고, 헷갈리기 쉬우면 `plus`에 개정 전 값을 적는다.
3. 사용자에게 보이는 글에 메타 문구를 넣지 않는다: "Claude", "사용자님", "제가", "도움이 되길", "참고로" 같은 말. 마크다운 기호(`**`, `##`)도 쓰지 않는다(앱이 그대로 보여 준다).
4. 한국어로, 시험 답안 문체로 쓴다. 영어 약어는 처음에 우리말과 함께 쓴다.
5. `field`는 관로·터널·환경시설 같은 현장 공무가 실제로 확인하는 서류·검사·수치와 이어지게 쓴다.
