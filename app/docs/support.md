# 기술사 6개월 지원

토목시공기술사 필기를 혼자 준비하는 사람을 위한 학습 앱입니다. 평일마다 학습 세트(용어 10개, 퀴즈 5문제, 논술 1문제, 과제)가 들어오고, 간격반복 카드, 기출 25회분(제116~140회) 문제 요지, 모의고사, 교시 타이머, 논술 답안 작성 요령을 씁니다. 비밀번호 없이 아이디만 만들고, 관리자가 승인하면 열립니다. 학습 기록은 휴대폰 안에만 있습니다.

## 자주 묻는 질문

**처음 열었더니 아이디를 만들라고 해요.**
관리자가 승인한 사람만 쓰는 앱입니다. 아이디(2~16자, 한글·영문 소문자·숫자·밑줄)를 넣고 "승인 요청 보내기"를 누르면, 관리자가 승인하는 대로 열립니다. 초대 코드를 받았다면 "초대 코드가 있어요"에 넣으면 바로 열립니다.

**승인을 기다리는 화면에서 넘어가지 않아요.**
앱을 켜 두면 잠시마다 다시 확인합니다. 관리자에게 아이디와 화면의 기기 번호를 알려 주세요. 한 번 승인되면 인터넷이 없어도 열립니다.

**아이디를 바꾸거나 다른 휴대폰에서 쓰고 싶어요.**
아이디는 휴대폰마다 하나로 고정됩니다. 바꾸려면 더보기 → 설정 → "아이디 지우기" 뒤 새로 만들고 다시 승인을 받습니다. 새 휴대폰에서는 새로 요청하고, 학습 기록은 아래의 백업·복원으로 옮깁니다.

**아이디를 완전히 지우고 싶어요.**
더보기 → 설정 → "아이디 지우기"를 누르면 아이디와 승인 정보가 바로 지워집니다. 학습 기록은 휴대폰에 그대로 남습니다.

**새 세트가 들어오지 않아요.**
세트는 평일 아침에 올라옵니다. 인터넷에 연결한 뒤 복습 → 세트 보관함 → "지금 받아 오기"를 눌러 보세요. "받아 오기 실패"가 계속되면 아래로 알려 주세요.

**휴대폰을 바꾸거나 기록을 따로 보관하고 싶어요.**
더보기 → 백업·복원에서 "백업 복사" 또는 "파일로 저장"으로 기록을 보관하고, 새 휴대폰의 같은 화면에서 복원에 붙여 넣으면 진도와 오답이 이어집니다.

**알림이 오지 않아요.**
더보기 → 설정 → 알림에서 켜고, iPhone 설정 → 알림 → 기술사 6개월에서 알림이 허용되어 있는지 확인하세요.

**타이머 알림음이 들리지 않아요.**
iPhone이 무음 모드이면 알림음이 나지 않을 수 있습니다. 무음 모드를 끄고 음량을 확인하세요.

**내용이 틀린 것 같아요.**
카드와 세트는 생성형 AI로 작성하고 일부를 기준 원문과 대조했습니다. 틀린 곳을 찾으면 그 카드를 숨기고 아래로 알려 주세요. 시험 전에는 교재와 최신 기준으로 한 번 더 확인하세요.
