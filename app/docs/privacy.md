# 기술사 6개월 개인정보 처리방침

시행일: 2026년 10월 20일

기술사 6개월(이하 "앱")은 토목시공기술사 필기 공부를 돕는 개인 학습 앱입니다. 관리자가 승인한 사람만 쓸 수 있도록, 사용자가 정한 아이디와 승인 상태만 저장합니다.

## 수집하는 정보

비밀번호 없이 아이디만 만드는 승인제입니다. 아이디를 만들면 아래 정보를 Google Firebase(Authentication, Cloud Firestore 서울 리전)에 저장합니다.

- 아이디: 사용자가 정한 2~16자 이름(실명이 아니어도 됩니다)
- 기기 번호: 앱이 처음 켜질 때 Firebase가 만든 무작위 계정 번호. 전화번호, 기기 일련번호, 광고 식별자, IP 주소로 만들지 않습니다
- 승인 상태(대기, 승인, 거절)와 아이디를 만든 시각, 승인 상태를 바꾼 시각
- 초대 코드로 만든 경우 그 코드

이름, 연락처, 이메일, 위치, 학습 기록은 받지 않습니다. 이 계정의 로그인 열쇠는 이 iPhone의 키체인에 "이 기기에서만"으로 보관해 다른 기기로 옮겨지지 않습니다.

## 쓰는 목적

- 관리자가 승인한 휴대폰만 앱을 열게 하고, 휴대폰마다 아이디를 하나로 고정합니다.
- 관리자는 앱의 승인 관리 화면에서 아이디, 승인 상태, 만든 날짜만 봅니다.
- 광고, 분석, 마케팅에 쓰지 않고 다른 곳에 팔거나 넘기지 않습니다. Firebase는 Google이 이 앱을 위해 운영하며, Google은 서비스 운영과 남용 방지를 위해 접속 기록(IP 주소 등)을 남길 수 있습니다([Firebase 개인정보 보호](https://firebase.google.com/support/privacy)).

## 휴대폰 안에만 저장하는 정보

- 학습 기록: 카드 진도, 오답 노트, 할 일 체크, 받은 세트와 모의고사, 시험 일정, 화면 설정
- 알림 설정: 켜 둔 알림과 시각

이 정보는 이 iPhone의 앱 저장 공간에만 저장되고 개발자나 Firebase에 보내지 않습니다. iPhone 백업(iCloud 백업 등)을 켜 두었다면 기기 백업에 함께 들어갈 수 있습니다.

## 인터넷을 쓰는 경우

새 매일 세트, 주간 모의고사, 기출 업데이트, 새 용어 풀이를 받을 때 GitHub(raw.githubusercontent.com)에 올려 둔 공개 파일을 HTTPS로 내려받습니다. 이 요청에는 학습 기록이나 개인 정보가 들어가지 않습니다. GitHub는 일반 웹 요청처럼 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 GitHub의 개인정보 처리방침을 따릅니다.

낱말 풀이 화면에서 "국어사전"이나 "지식백과"를 누르면 사파리에서 네이버 검색 페이지가 열리고, 그 낱말이 검색어로 전달됩니다. 이 버튼을 누르지 않으면 낱말 풀이는 휴대폰 안의 카드와 용어 사전만 씁니다.

## 광고, 분석, 추적

광고, 사용 분석, 오류 보고, 추적 도구가 없습니다. 위의 Firebase 외에는 제3자에게 정보를 제공하지 않습니다.

## 권한

- 알림: 설정에서 알림을 켤 때만 허용을 묻습니다. 알림은 서버 없이 휴대폰 안에서 예약합니다.
- 클립보드: 복사 버튼을 누를 때만 글을 복사합니다.
- 파일 내보내기: 백업의 "파일로 저장"을 누를 때만, 공유 시트에서 고른 곳으로 백업 파일을 보냅니다.

## 보관 기간과 삭제

- 아이디와 승인 정보: 아이디를 지울 때까지 보관합니다. 앱 안의 더보기 → 설정 → "아이디 지우기"(승인 전이면 첫 화면의 "아이디 지우기")를 누르면 Firebase의 아이디, 승인 정보, 계정이 바로 지워집니다. 관리자가 승인 관리에서 그 아이디를 지울 때도 아이디와 승인 정보가 지워집니다.
- 앱만 지우면 Firebase의 아이디는 남고, 다시 설치하면 대개 같은 아이디로 이어집니다. 완전히 지우려면 앱을 지우기 전에 "아이디 지우기"를 누르거나 지원 페이지로 요청해 주세요.
- 학습 기록: 앱을 지울 때까지 휴대폰에 남습니다. 앱을 지우면 함께 지워지고, 앱 안의 더보기 → 백업·복원 → 전체 초기화로도 지울 수 있습니다.
